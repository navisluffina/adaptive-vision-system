# Adaptive Vision System

## Overview
This project is an adaptive computer vision system that detects image quality issues such as low light and blur, and enhances them.

## Features
- Detects low light and blur
- Enhances image using CLAHE and denoising
- Shows original vs enhanced comparison
- Saves enhanced frames automatically

## Technologies
- Python
- OpenCV
- NumPy

## How to Run
pip install -r requirements.txt  
python main.py

## Output
Saved in: output/images/
